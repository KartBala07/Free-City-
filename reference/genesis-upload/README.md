User-supplied GENESIS prototype sources, preserved for reference. These files are not deployed as a second game. Brain forward/reward learning is adapted in src/brain.js; needs and illness concepts in src/life.js; ranked brain/instinct diagnostics in src/inspector.js; directional walking and illness appearance in src/people.js. The uploaded legacy Three.js bundle is superseded by the pinned Three.js dependency used by the main project. Original terrain, global variables, accelerated ages and nation/war systems are not merged into the San Francisco engine.
